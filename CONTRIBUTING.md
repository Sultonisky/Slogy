# Contributing to Slogy

Thank you for considering contributing to Slogy!

## 🐛 Reporting Bugs

If you find a bug, please create an issue with the following details:
- Clear description of the bug
- Steps to reproduce
- Screenshots (if applicable)
- Laravel and PHP versions you're using

## ✨ Proposing New Features

For feature requests, please create an issue and explain:
- What feature you'd like to add
- Why this feature is important
- Example usage (if possible)

## 🛠️ Pull Requests

1. **Fork this repository**
2. **Create a new branch** (`git checkout -b feature/feature-name`)
3. **Commit your changes** (`git commit -m 'feat: Add new feature'`)
4. **Push to the branch** (`git push origin feature/feature-name`)
5. **Create a Pull Request**

## 📝 Coding Standards

- Follow **Laravel Coding Standards**
- Run tests before creating a PR (`vendor/bin/phpunit`)
- Add tests for new features
- Update documentation in README (if needed)

## 🚀 Development Setup

1. Fork and clone the repository
2. Run `composer install` in the `packages/slogy` directory
3. Run tests with `vendor/bin/phpunit`

Happy contributing! 🎉
